Slide Editor

在任何 HTML 演示文稿上启用可视化编辑器

使用方法：拖拽书签工具

  1. 将下面的按钮拖拽到您的浏览器书签栏
  2. 打开您想要编辑的 HTML 演示文稿文件
  3. 点击书签栏中的 "Slide Editor" 书签
  4. 编辑器将自动加载并启用

Slide Editor

提示：拖拽上面的按钮到浏览器书签栏。如果看不到书签栏，按 Ctrl/Cmd + Shift + B 显示。

方法 2：URL 参数

如果您控制 HTML 文件的 URL，可以在 URL 后添加 ?edit=1 参数：

http://localhost:8888/Amicus-宣讲PPT-测试badcase/amicus-presentation.html?edit=1

方法 3：浏览器控制台

在浏览器中打开演示文稿，按 F12 打开控制台，粘贴以下代码：

var s=document.createElement('script');
s.src='http://localhost:8888/dist/editor.bundle.js';
document.body.appendChild(s);
s.onload=function(){window.__openclawEditor.enable();};

前提条件

确保本地服务器已启动并运行在 http://localhost:8888
运行命令：python3 -m http.server 8888

支持的演示文稿

本编辑器设计用于标准的 HTML 演示文稿，具有以下特征：

  • 每张幻灯片使用 <div class="slide"> 包裹
  • 支持文本、图片、标题等常见元素
  • 支持动画包装元素（如 .reveal 类）
